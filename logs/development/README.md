# Предварительные прогоны

Здесь сохранены журналы отладки, а не два опыта из отчёта.

- `unsafe-20261024T182627`: ошибка вызова API транзакции Kazoo до первой публикации чекпоинта. Исправлено добавление операций без цепочки вызовов.
- `unsafe-20261024T182655`: приостановлен процесс-обёртка Windows venv, вычисляющий дочерний процесс продолжил работу. Этот прогон не использован как опыт отказа. Также исправлена синхронизация записи журнала из потоков.

В итоговом оркестраторе PID берётся из события самого вычисляющего процесса. Отдельная проверка подтверждает отсутствие событий A в течение всей паузы. Два принятых опыта: `unsafe-20261024T182821` и `fenced-20261024T182954`; их журналы лежат уровнем выше, числовые итоги — в `evidence/experiments.json`.
